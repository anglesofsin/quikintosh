# Droppy reference audit, 26 November 2026

Reviewed official product pages, the settings/notch documentation and feature
screenshots. The researched catalogue included 16 built-in surfaces and 53
extensions; these are separate scopes, not two rendering themes. The two primary
shapes are an edge-attached notch and a detached island, independently selectable
for display types. No Droppy artwork, Swift code or proprietary service endpoints
are bundled in Quickintosh.

## Design translation

Black rounded surfaces remain the default. The expanded island is a shelf with
up to four independent modules. A small Home/Files/Widgets/Media navigator replaces
the long tab row by default; expanded tabs remain optional. Artwork, title,
secondary metadata, progress and playback controls occupy distinct rows. Files
use preview cards with concise metadata. Controls use existing vector artwork,
SF Pro and restrained gray fills. Surface dimensions, motion duration, hover and
collapse delays and materials are settings, not separate shell implementations.
Native compositor glass and a black-to-glass gradient are optional. No wallpaper
sampling shader or periodic screenshots are added to implement these materials.

## Implementation map

| Area | Quickintosh implementation / limit |
|---|---|
| Notch / island | Separate built-in/external display shape choices; existing fullscreen/lock/privacy owner retained |
| Shelf widgets | Four slots, size weights, drag to swap and mouse resize handles in Arrange mode |
| Home | Media, calendar, weather, focus, notes, system and files modules |
| File tray | Reference-only drops, persistent pins, remove, clear unpinned, open, Finder reveal, Quick Look, URI clipboard, ZIP and static image conversion |
| Floating file tray | Independent movable window sharing the same references |
| Clipboard | Search/copy existing local text/image history; no second capture daemon |
| Media | Existing MPRIS selection and playback; shelf progress/seek and standalone player |
| Floating player | Mini/Player/Lyrics layouts, movable window, native glass option |
| Lyrics | Existing synchronized provider, current-line tracking, click to seek, blank-on-unavailable default |
| Notifications | Existing notification owner, preview/body, app-provided actions, focus toggle, removal transitions |
| Weather | Existing forecast provider and artwork; no second network poller |
| Calendar | Existing local calendar provider; Apple Calendar/Reminders sync is not implemented |
| Notes | Existing local notes store/editor; Apple Notes sync is not implemented |
| Focus / timers | Existing focus/timer sources and controls retained |
| Audio Control | PipeWire playback stream volume and mute controls |
| Stay Awake | Timed user-requested systemd idle inhibitor; no permanent power-policy change |
| Live Activities | Existing call, download, recording, timer, power, network/VPN and other sources retained; bounded local activity IPC added |
| Capture / Text Capture | Buttons route to existing Quickshot and OCR implementation |
| System HUDs | Existing island volume/brightness source retained |
| Camera | Existing opt-in camera preview retained; starts only through user controls |
| Window previews / snap / emoji / mouse | Existing Quickintosh subsystems retained; not rewritten by shelf integration |
| Playing Next | Full queue read/reorder not implemented; MPRIS does not promise a track list for every player |
| Motion artwork / lock-screen depth | Full Droppy-equivalent motion/depth processing not implemented |
| Agent/build activity | Generic local progress API, not automatic Claude/Codex/Xcode interception |
| Custom third-party Droplets | DroppyKit/Swift extensions are not loaded on Linux |
| iPhone / Beam / Droppy Cloud | Proprietary account, mobile client, cloud and encrypted sync not implemented |
| Apple Music / Things / Xcode / CleanMyMac | Apple-specific integrations not implemented; no fabricated compatible service |
| Commercial/API extensions | Sales, market quotes, Plane, Obsidian sync, translation, transcription and remote AI-account integrations require individual providers; not implemented by this shelf |
| Extra utilities | Action Ring, fringe gestures, cleanup, teleprompter and magnifier parity not implemented |

This is an implementation ledger, not a claim of complete Droppy parity. Platform
and provider-specific work must be separately implemented and tested before its
status changes. No disabled decorative controls stand in for missing providers.
