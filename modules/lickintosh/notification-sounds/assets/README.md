# Notification tones

Rebound is the default tone. The CAF source in SOURCES.json is byte-identical (SHA-256 c802ae28a87d08f9a3d42e8eef27a7c1c052cf55fad996f74e2e8314ff1ee420) to the Rebound-EncoreInfinitum.caf documented in the macOS 26.6.1 inventory. It was obtained from the public iOS 26 archive; the matching hash confirms the same source asset.

Glass and Ping are alternate Apple system tones from the macOSsystemsounds archive. The source audio was decoded to 48 kHz stereo PCM WAV without synthesizing or replacing the original sounds. URLs and original hashes are recorded in SOURCES.json.

Apple audio assets retain their original rights; the GPL license of the integration code does not relicense the sounds. Inventory: https://notification-sound-db.semnil.com/sounds/c802ae28a87d08f9a3d42e8eef27a7c1c052cf55fad996f74e2e8314ff1ee420.html
