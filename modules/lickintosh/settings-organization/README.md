The grouping and compact visual proportions are adapted to Quickintosh's actual
pages from MacShell's System Settings design, reviewed at vladbiber/macshell.
https://github.com/vladbiber/macshell/blob/main/MacShell/MacDock.qml

Quickintosh retains its native HyprGlass integration and its existing settings
backends. This integration does not install MacShell, run its installer or copy
its configuration over the user's rice.
