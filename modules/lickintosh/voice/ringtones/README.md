# Call ringtones

Opening (default in this rice) and Reflection are original Apple ringtone recordings from the macOSsystemsounds archive. SOURCES.json records URL and hash. Opening follows the traditional FaceTime default; the project does not claim this is the unchanged default for every Tahoe configuration. Files are not synthesized reproductions. Copyright belongs to the respective rights holders; GPL licensing of the code does not relicense these recordings.

Apple's ringtone settings: https://support.apple.com/en-asia/guide/facetime/fctm1045f51f/mac
